Follow `docs/writing.md`. In short:

- Write the reason, not what the code or the name already shows.
- Use at most 25 words in a sentence. Use the active voice.
- Do not use contractions, phrasal verbs, hedging or marketing words.
- Do not write history (`previously`, `now`). Put release notes in `docs/migrations`.
- Put identifiers, commands and field names in backticks.
